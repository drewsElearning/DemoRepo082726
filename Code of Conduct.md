# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, inclusive, and respectful environment for everyone participating in this repository. This project exists to support learning, collaboration, and professional growth within the GitHub and GitHub Copilot ecosystem.

We pledge to make participation in our project a harassment-free experience for all contributors, regardless of:

- Age
- Disability
- Ethnicity
- Gender identity or expression
- Level of experience
- Nationality
- Personal appearance
- Race
- Religion
- Sexual orientation
- Technical background

## Expected Behavior

All community members are expected to:

- Be respectful and professional in discussions.
- Provide constructive feedback.
- Assume positive intent.
- Be welcoming to new contributors and learners.
- Focus on ideas, not individuals.
- Share knowledge openly and help others learn.
- Follow GitHub Community Guidelines and Terms of Service.

## Unacceptable Behavior

The following behaviors are not tolerated:

- Harassment or discriminatory language.
- Personal attacks or insults.
- Trolling, inflammatory comments, or disruptive behavior.
- Publishing private or confidential information without permission.
- Spam, solicitation, or malicious activity.
- Any conduct that would be considered inappropriate in a professional workplace.

## Collaboration Guidelines

When contributing to this repository:

1. Be respectful during code reviews.
2. Keep discussions focused on the project.
3. Document changes clearly.
4. Follow established repository standards.
5. Help maintain a positive learning environment.

## Reporting Issues

If you experience or witness behavior that violates this Code of Conduct, please report it to the repository maintainers.

When reporting an issue, include:

- A description of the incident
- Relevant links or screenshots, if applicable
- The date and time of occurrence
- Any additional context that may be helpful

All reports will be reviewed promptly and handled with discretion.

## Enforcement

Repository maintainers have the authority to:

- Remove inappropriate comments or content
- Request corrective action
- Restrict participation temporarily or permanently
- Remove contributions that violate this Code of Conduct

Decisions made by repository maintainers are intended to protect the integrity of the project and its community.

## Scope

This Code of Conduct applies to:

- Repository discussions
- Issues
- Pull requests
- Project boards
- Wikis
- GitHub Discussions
- Any other community interaction associated with this repository

## Acknowledgments

This Code of Conduct is inspired by established open-source community standards and adapted for educational and demonstration purposes.

Thank you for helping create a positive, inclusive, and collaborative learning environment.

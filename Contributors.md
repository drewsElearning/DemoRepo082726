# Contributors

Thank you to everyone who has contributed to the **GH-900 GitHub Foundations Demo Repository**.

This file provides learners with an opportunity to practice the GitHub collaboration workflow, including creating branches, editing files, committing changes, and submitting pull requests.

---

## How to Add Your Name

1. Create a new branch from the default branch.
2. Open the `CONTRIBUTORS.md` file.
3. Add your information to the contributor table.
4. Commit your changes with a meaningful commit message.
5. Push your branch to GitHub.
6. Create a pull request.
7. Review and merge the pull request when approved.

> [!IMPORTANT]
> Do not include personal or sensitive information. Only provide information that you are comfortable sharing in the repository.
